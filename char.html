Character Creator

Part of my Programming Algorithms and Techniques Module

This is a character creator project that i made and it utilizes UI buttons and sliders to allow the user to select there choice of clothing and then assigns this to the character model as well as allowing the user to change the colour of there character, the size of them and allowing them to change there name too! Furthermore, there is a rotation tool that allows the player to rotate the character so they can see all parts of it!
