Lyra Game

Part of my Level Design Module

This was a lyra based project which if you don't know is a framework for unreal engine and basically allows us to focus less on the back-end of how it all works and put the main focus on the actual level making itself. For this assignment i made my multiplayer level which was meant to be a post-apocolyptic london based level however a lot of this theme was lost by the final submission just mainly due to time constraints of this project. However, one really useful part of this module was it showed me how to collect and process feedback and then adapt this into improving my level. This was a really useful skill as it enabled me to showcase how i can clearly recieve critisism and feedback and tweak and improve my work based upon it.
