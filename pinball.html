Pinball Game

Part of my Game Engine Scripting Module

This pinball game was an assignment for one of my first ever modules Game Engine Scripting. This game was designed to be a mobile game at its core and was designed to showcase how i could not only use and read another method of player input but also showcased how i was able to use physics based systems and how i adapted this for my pinball game. For example, we were given a starting point for how to make the pinball arms and i then tweaked and adapted this to not only change the amount of force that was expelled upon collision but also re-used this for the point collecters throughout the levels as these also had systems on them to move the player around in fun and engaging ways.
