Signal Lost Game

Part of my Professional Awareness Module

Signal lost was a group project i did with a classmate (a designer) and the idea behind the game was to create a story driven experience about someone working in a remote signal tower who wakes up to discover everyone is missing and that they have no memory of where they are or how they got there. Unfortunatly, due to the short timeframe nature of game jams, we only managed to get the start of the game complete, but we did leave the game on a cliffhanger for possible future expansion...

These are some of the scripts that i worked on to make this game. The top one is a simple raycast script which just helps me determine where to the player is looking and what they can interact with. Additonally, i use this script to start a lot of the minigame because as soon as the player looks at an interactable object a message will appear guiding them on how to interact with the object and then the script will start the script for said minigame.

The bottom script is used for the repair wires minigame and it basically works off of buttons and invisible lines which appear when the user has connected the two ends of the wires and then once all the wires are connnected the "power turns on" which is just a lighting effect to create that feeling.
